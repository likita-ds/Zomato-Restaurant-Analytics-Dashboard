🍽️ Zomato Restaurant Analytics Dashboard
📊 Project Overview

The Zomato Restaurant Analytics Dashboard is an interactive Power BI project designed to analyze restaurant data and provide meaningful insights into restaurant ratings, pricing, cuisines, locations, and customer preferences.

The dashboard helps users explore restaurant performance through interactive charts, filters, and KPIs, making it easier to identify trends and compare restaurants across different categories.

🎯 Objectives
Analyze restaurant ratings and customer preferences
Understand the relationship between price range and ratings
Identify popular cuisines and restaurant categories
Analyze the average cost for two people
Compare restaurant performance across different locations
Create an interactive and user-friendly Power BI dashboard
